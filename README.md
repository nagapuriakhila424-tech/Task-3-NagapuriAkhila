# 📊 SQL Data Analysis Project

## 🎯 Objective
To analyze business data using SQL and Python, generate meaningful insights, and support data-driven decision-making through database querying and analysis.

## 📝 Description
This project focuses on SQL Data Analysis using Python, Pandas, and SQLite. The dataset is cleaned, stored in a SQLite database, and analyzed using SQL queries. Various SQL operations are performed to extract valuable business insights and understand key performance metrics.

## 🛠️ Tools & Technologies Used
- Python
- Pandas
- SQLite3
- Jupyter Notebook

## 🔍 SQL Concepts Implemented
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- WHERE + GROUP BY + ORDER BY

## 📋 Project Workflow
1. Load Dataset
2. Perform Data Quality Checks
3. Clean Data
4. Create SQLite Database
5. Create SQL Table
6. Execute SQL Queries
7. Generate Business Insights
8. Draw Conclusions

## 📈 Business Insights Generated
- Total Orders
- Total Revenue
- Average Order Value
- Product-wise Revenue Analysis
- Payment Method Analysis
- Order Status Analysis
- High-Value Product Analysis
- Top Revenue Generating Product
- Top 5 Highest Value Orders

## 📊 Project Preview
The complete SQL Data Analysis project, including data cleaning, database creation, SQL queries, analytical outputs, and business insights, can be viewed directly in the Jupyter Notebook available in this repository.

👉 Open **SQL Data Analysis Project.ipynb** to explore the complete workflow, SQL operations, and analysis results.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Install the required Python librariers:
       - Pandas
       - Numpy
       - Matplotlib
       - Seaborn
       - Juypter Notebook
4. Open `SQL Data Analysis Project.ipynb` in Jupyter Notebook.
5. Run all the notebook cells to execute the SQL queries, analyze the data, and view the results.
